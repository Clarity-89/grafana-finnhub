These pages are for a Grafana instance that already has the Finnhub data source installed. They cover connecting the data source to Finnhub, building queries for quotes, company data, news and calendars, and using the data source in dashboards with template variables and annotations.

## Recommended path

Start with **Configure** to connect Grafana to Finnhub with an API token, then read **Query editor** to build your first query and learn what each data type returns. When you move on to dashboards, add **Template variables** for repeatable panels and **Annotations** to mark news and calendar dates on graphs.

## Common tasks

- [Connect Grafana to Finnhub](./configure.md)
- [Build a query for quotes, profiles, news or calendars](./query-editor.md)
- [Filter dashboards with template variables](./template-variables.md)
- [Show company news and calendar dates on graphs](./annotations.md)
- [Fix connection, authentication and query errors](./troubleshooting.md)
